##  THE GARAGE LOG

###  Project: WillowTree // Deep Learning & Chess
Right now, I am dismantling chess from true zero. Standard engines rely on stiff, massive calculation trees that fracture when things get weird. I want to build something fluid. I am learning how to weld an ultra-fast C++ bitboard move generator to a PyTorch transformer network. The goal is an engine that uses raw pattern intuition to hunt down structural anomalies and challenge the 4000+ Elo frontier. ###  Project: Beatrice // Metal & Microcontrollers
My summers aren't spent at clean corporate internships; they are spent choking on grass clippings from a gas mower to fund this garage workshop. Beatrice is a Frankenstein café racer fusing a vintage British chassis with a sharp, high-contrast aesthetic. I don't just bolt on parts. I am learning to measure frame tolerances with digital calipers, model linkages in SolidWorks, and write bare-metal C++ microcontroller firmware to run sequential LED relays from scratch. I refuse to ride a system I didn't map myself.

###  Vector: High-Pressure Systems // NAUI Diving & Flight

I am carrying that exact cockpit discipline over to my student pilot flight hours and Eagle Scout logistics.
